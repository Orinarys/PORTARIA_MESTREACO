# 🚀 GUIA RÁPIDO - INÍCIO EM 3 PASSOS

## Para usuários Windows:

### Passo 1: Instalar Python
1. Baixe em: https://www.python.org/downloads/
2. Execute o instalador
3. ⚠️ **IMPORTANTE**: Marque "Add Python to PATH"
4. Clique em "Install Now"

### Passo 2: Instalar o Sistema
1. Extraia todos os arquivos em uma pasta
2. Dê duplo clique em `instalar.bat`
3. Aguarde a instalação

### Passo 3: Executar
1. Dê duplo clique em `executar.bat`
2. Pronto! O sistema abrirá

---

## Para usuários Linux/Mac:

```bash
# Instalar dependências
pip3 install -r requirements.txt

# Executar
python3 sistema_portaria.py
```

## 🆘 PROBLEMAS COMUNS

**"Python não reconhecido"**
→ Reinstale Python marcando "Add to PATH"

**"Erro ao validar CPF"**
→ Normal se estiver sem internet. Sistema valida localmente

**"Campos obrigatórios vazios"**
→ Preencha todos os campos com asterisco (*)
